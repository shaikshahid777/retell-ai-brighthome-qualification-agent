# Limitations and Next Steps

## Known limitations

1. **Official ZIP-code list unavailable:** The supplied assessment materials did not contain approved service-area ZIP codes. Do not invent them. Confirm eligibility against an official list before marking a caller qualified.
2. **Complete supported-services list unavailable:** Commercial/office cleaning is explicitly treated as out of scope, but the full approved residential service list was not supplied.
3. **Live availability is not integrated:** The agent cannot confirm real appointment slots.
4. **Booking is not verified:** The agent should not claim that an appointment has been booked.
5. **Educational prototype only:** Verify business policy, privacy/data handling, and integrations before production use.

## Recommended next steps

- Obtain the official service-area ZIP list and approved services from the instructor/business owner.
- Update the prompt only after receiving verified business data.
- Re-run the assessment test cases after any prompt changes, with the project owner's authorization.
- Capture sanitized screenshots of agent configuration and simulation results.
- Keep the Loom walkthrough and LMS description linked from the README.
